# FLICKPICK - Movie Recommendation Platform

A modern movie recommendation platform with personalized suggestions based on user preferences.

## Features

- 🎬 Personalized movie recommendations
- ❤️ Watchlist management
- ⭐ User reviews and ratings
- 📊 Genre-based preferences
- 🎯 ML-powered suggestions

## Live Demo

Visit: [your-domain.com](https://your-domain.com)

## Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Backend**: Django REST Framework
- **ML API**: Flask with scikit-learn
- **Database**: PostgreSQL
- **Deployment**: Hugging Face Spaces + Render

## Quick Start

1. Clone this repository
2. Run locally with Django backend
3. Deploy to Hugging Face Spaces

## API Endpoints

- `/api/recommendations/` - Get personalized recommendations
- `/api/watchlist/` - Manage watchlist
- `/api/reviews/` - User reviews
- `/api/preferences/` - User preferences
